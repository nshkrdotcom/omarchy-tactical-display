## Context and detail completeness

Stable process-instance IDs, application IDs, mount/device IDs, remote IDs and PipeWire runtime serial identities cross the shared navigation boundary. Destination instruments resolve the exact identity where present and say when it is unavailable. Search covers relevant raw fields even when primary labels are hidden by density. Frozen detail pages belong to the frozen helper snapshot; if that buffer is lost after a restart, the UI does not silently substitute live details.

## Conditional features and non-goals

Optional GPU/thermal, system reverse DNS, user-provided offline enrichment and confirmed mute/default/undo have real production paths and explicit capability/opt-in rules. The default is local, unprivileged and observation-first. Workspace/Agent Topology remains conditional on all P0 gates and reliable state sources; stream rerouting needs a reliable serial-safe route API before exposure. No packet capture, persistent traffic logging, unmeasured per-link bandwidth, destructive disk/process controls, privileged daemon or standalone second Quickshell is part of this release.

## Native gate sequence

1. Apply and verify the exact overlay, then native manifest + QML lint and load. Fix any plugin-local error before proceeding.
2. Exercise all five modes, keyboard/pointer/control traversal, help/settings/privacy, context transfer, freeze/details and invocation. Validate the true PipeWire and optional hardware/enrichment sources.
3. Execute 50 native lifecycle cycles and the 30-minute runner; review actual shell logs and open/closed resource deltas.
4. Perform monitor/hotplug/bar/reload and the full native screenshot/reviewer matrix. A failing visual gate must be fixed, not relegated to a vague polish note.
5. Record installed commits/versions, commands, captures, measurements, precise outcomes and any actual defect; rebuild a new incremental overlay with pristine reconstruction.

Copy/paste commands and safe workload generation are in [HANDOFF.md](HANDOFF.md). Current evidence and skipped integrations are in [VALIDATION.md](VALIDATION.md).
